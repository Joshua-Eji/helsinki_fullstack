# Full Stack Open

My work through [Full Stack Open](https://fullstackopen.com/en/), the University of Helsinki's open course on modern JavaScript web development.

I took this on after a year and a half of building React applications professionally, to fill in the parts I had learned by doing rather than by understanding - how requests actually move through a single page application, and what the framework is doing on my behalf.

## Progress

Part 0, Fundamentals of web apps - done

Part 1, Introduction to React - done

Part 2, Communicating with server - in progress

## Part 0, Fundamentals of web apps

Sequence diagrams tracing what the browser and server exchange in a traditional form-submitting page versus a single page application, and what changes when a new note is created in each. Diagrams are in the Part 0 folder, written in Mermaid.

## Part 1, Introduction to React

React fundamentals built up from components and props to state and event handlers.

Header, Content and Total are the course information exercises - splitting a page into components and passing data down as props.

Button, StatisticsLine and the feedback app cover useState, event handlers and conditional rendering.

Built with Vite. To run it, change into the part 1 directory, then npm install and npm run dev.
